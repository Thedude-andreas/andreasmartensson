Android beta

AMC Download Manager

Open your most recent download with one tap. AMC Download Manager keeps the latest file within easy thumb reach and adds focused tools for sharing, renaming, and deleting downloaded files.

Version 1.1.0-beta.1 · Android 8.0 or newer

What to test

  • Grant file access and confirm Downloads appears.
  • Open the newest file using the orange action.
  • Open, share, rename, and delete files from the list.
  • Add and remove an extra folder.
  • Try different file types and a folder with many files.

Privacy by design

  • No account, ads, analytics, or remote data collection.
  • File information is processed locally on the device.
  • Files are shared only when you explicitly choose Share.
  • File access can be revoked in Android settings at any time.
